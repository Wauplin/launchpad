Set up Launchpad Home

Home keeps your sessions, branches and settings in a private bucket. Agents run on your own machines. The required steps take 10 to 15 minutes, most of it signing in to Hugging Face, GitHub and your agent subscription.

  1. Hugging Face

    Home uses this login to reach its private bucket .

  2. Credential key

    Encryption is on. The key is the LP_HOME_KEY secret of this Space: keep your copy, Home needs it to restore its credentials if the Space is ever deleted.

    Home encrypts every credential it stores (logins, tokens, SSH key) with this key. Save it somewhere safe: you need it to restore Home if its Space is ever deleted.

    Home must restart to finish this step
    • It saves your key as the LP_HOME_KEY secret of this Space.
    • It turns on encryption for the credentials in its bucket.
    • It keeps your Hugging Face sign-in.
    The restart takes about a minute. This page reconnects by itself.
    Add the key to the Space yourself

    This Hugging Face login cannot change the Space settings. Open the Space settings, add a secret named LP_HOME_KEY and paste your key as its value. Saving the secret restarts Home.

    Home is restarting with your key. This page reconnects by itself.

  3. GitHub

    Used by the Inbox, issues, pull requests, private clones and publication. Home keeps this login encrypted. Agents never get it: they get their own tokens from Credentials and tools.

  4. SSH key

    You need it only to push over SSH from a runner's own clone: agents push to Home Git, and the GitHub sign-in already covers clones. The private key never leaves Home.

    Add the public key to your GitHub account:

    Open the GitHub page below, paste the key, name it “Launchpad Home” and click Add SSH key. How to add an SSH key

    Open GitHub SSH settings

  5. Git identity

    The author of your agents' commits, on every runner.

    Your GitHub noreply address keeps your email private.

  6. Agent profile

    A profile is how agents run. Sign in with your subscription: Home keeps the login encrypted and lends it to runners for each session.

    Choose the model and effort each profile's agents use by default. You can change them for each launch.

    Use both agents? Sign in to the other one now: each login becomes its own profile.

  7. Workspace and first folder

    A workspace groups related folders, for example “Work” and “Personal”. Create at least one, then clone a repository from GitHub into it.

  8. Where agents run

    Your Linux x86_64 laptop recommended for daily work Agents run there in a jail, at your disk's speed. Runners need Linux on x86_64: on a Mac or an ARM machine, use Burst. On your Linux laptop or a Linux server, run this in a terminal:
