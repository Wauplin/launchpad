# Harness logos

- `claude.svg`: the Claude logo shipped by Anthropic in the Claude Code VS Code extension (`resources/claude-logo.svg`, version 2.1.287), unchanged.
- `codex.svg`: the Codex app mark (cloud with `>_`) with the gradient of the official Codex app icon. The vector shape comes from `@lobehub/icons-static-svg` 1.95.1 (`icons/codex.svg`, MIT), because the Codex VS Code extension ships the mark only as a PNG.
