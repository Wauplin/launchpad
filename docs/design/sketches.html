  1. 1Pending, Running, Closed. A pending session waits for your input, or only waits for a background command. It stays pending until you close it (×). Closed sessions can be resumed. A desktop notification fires when a session becomes pending, even with the window closed.
  2. 2Layouts 1, 2 and 4. Ctrl+1, Ctrl+2, Ctrl+4. Clicking a session loads it in the focused pane (teal outline). Dragging picks another pane.
  3. 3Session header. Project, state and elapsed time, tokens, context usage and cost (Claude only). Interrupt with Esc. "Open in terminal" hands the session to Ghostty and back.
  4. 4Compact tool calls. Commands and file reads collapse into one line, edits show a small diff, the running command has a spinner. Click to expand.
  5. 5Copy exactly. Each message has Copy (raw markdown) and Copy as text, and code blocks have their own button. No terminal line breaks or padding.
  6. 6Questions become buttons. When an agent asks something, its options are clickable and numbered. Typing a free answer still works.
  7. 8Background commands. When the agent only waits for a long command, the session shows an outlined "Background" badge with the latest output. It moves back to Running when the agent picks up again.
  8. 7Type while it works. A message sent during a turn steers Codex right away, or is read by Claude after its current step.
